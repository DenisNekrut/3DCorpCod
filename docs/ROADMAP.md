## Правило перехода
Этап считается завершённым только после:
1. реализации требований;
2. тестирования;
3. прохождения GitHub Actions;
4. проверки результата в опубликованном приложении, если затронут веб-интерфейс;
5. обновления документации и закрытия соответствующей Issue.

## Источник фактического прогресса
Статусы в этом файле — сводка. Фактические события и обсуждения фиксируются в Issues, Pull Requests, коммитах и Actions. Не отмечать этап выполненным только по факту создания ветки или файлов.
