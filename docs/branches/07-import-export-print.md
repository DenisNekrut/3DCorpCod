# Ветка 07 — Импорт, экспорт и 3D-печать

**Git branch:** `feature/07-import-export-print`

## Задачи
- Экспорт выбранных объектов в отдельные STL.
- Экспорт всей сцены в STL с сохранением взаимного положения.
- Экспорт 3MF.
- Импорт поддерживаемых форматов и собственных проектов.
- Явная обработка единиц и масштаба; внутренний стандарт — мм.
- Проверки сеток и предупреждения о проблемной геометрии.

## Приёмка
Файлы имеют ожидаемые габариты, проверяются независимым слайсером и сохраняют взаимное расположение объектов.
