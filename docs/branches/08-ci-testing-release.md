# Ветка 08 — CI, тестирование и релиз

**Git branch:** `feature/08-ci-testing-release`

## Задачи
- Проверка типов, сборка и тесты в GitHub Actions.
- Отдельный workflow публикации GitHub Pages.
- Проверка base path и путей ресурсов.
- Тесты трансформаций, сохранения, булевой геометрии и экспорта.
- Ошибки проверок должны блокировать публикацию.
- Документирование релиза и отката.

## Приёмка
PR не проходит без успешных обязательных проверок; деплой проверяет доступность сайта и загрузку ресурсов.
