# Ветка 04 — Булева геометрия

**Git branch:** `feature/04-boolean-geometry`

## Задачи
- Объединение, вычитание и пересечение.
- Режим отверстия/инструмента вычитания.
- Пересчёт параметрической операции при изменении исходных объектов, если поддерживается деревом операций.
- Эталонная модель: прямоугольный корпус с полостью, отверстиями и отдельной крышкой.
- Предпросмотр, диагностика и Undo/Redo.

## Приёмка
Результат соответствует тестовым эталонам; ошибка не портит исходные объекты; STL проходит проверку в слайсере.
