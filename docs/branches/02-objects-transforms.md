# Ветка 02 — Объекты и трансформации

**Git branch:** `feature/02-objects-transforms`

## Задачи
- Примитивы: коробка, цилиндр, сфера, конус, призма и дополнительные параметрические формы.
- Текстовый объект с настройками.
- Выбор одного и нескольких объектов.
- Перемещение, вращение, масштабирование и отражение.
- Числовые поля координат и габаритов в сцене и панели свойств.
- Центр объекта — pivot по умолчанию.
- Исправление отката позиции/размеров после снятия выделения.

## Приёмка
Введённые значения сохраняются; drag не вызывает скачков; трансформации воспроизводимы и покрыты тестами.
