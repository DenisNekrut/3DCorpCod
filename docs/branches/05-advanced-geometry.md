# Ветка 05 — Расширенная геометрия

**Git branch:** `feature/05-advanced-geometry`

## Задачи
- Выбор рёбер/граней.
- Фаски с числовым параметром и предпросмотром.
- Скругления с радиусом и предпросмотром.
- Дополнительные параметрические формы.
- Безопасный отказ при невозможной операции.

## Приёмка
Параметры применяются на поддерживаемых типах геометрии; неудачная операция не повреждает исходную модель.
