# Ветка 00 — Архитектура

**Git branch:** feature/00-architecture  
**GitHub Issue:** [#5 — Утвердить архитектуру и геометрическое ядро](https://github.com/DenisNekrut/3DCorpCod/issues/5)

## Цель
Зафиксировать техническую основу до масштабной реализации.

## Текущий результат
Подготовлен архитектурный документ [ARCHITECTURE_DECISION.md](../ARCHITECTURE_DECISION.md). В нём описаны:
- фактический стек и существующие модули;
- архитектурные риски текущей реализации;
- целевая структура каталогов;
- контракты доменной модели, геометрического ядра, viewport, хранения и экспорта;
- план технических проверок и критерии завершения.

## Подтверждённый текущий стек
- React 19 + TypeScript + Vite 6;
- Three.js + React Three Fiber + Drei;
- Zustand;
- three-bvh-csg для булевых операций;
- IndexedDB для локального хранения;
- STL, 3MF и OBJ экспорт.

## Следующие задачи
- Запустить чистую установку зависимостей, сборку и тесты.
- Добавить тесты примитивов и булевых операций.
- Проверить повторную оценку геометрии и освобождение ресурсов.
- Сверить viewport, preview и экспорт на контрольных моделях.
- После тестов вынести вычисление геометрии в единый GeometryKernel.

## Приёмка
- Архитектура утверждена.
- Сборка и тесты проходят воспроизводимо.
- Прототип отображает примитив, выполняет тестовую булеву операцию и сохраняет/загружает проект.
- Ограничения и лицензии зависимостей задокументированы.

## Не входит
Полная реализация всех пользовательских функций и массовая миграция файлов без промежуточных проверок.

## Текущий статус
Архитектурный аудит и документ выполнены. Сборка и тесты в чистом окружении ещё не запускались. Задача остаётся открытой.
