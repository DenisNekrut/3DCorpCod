## Как отслеживать прогресс
- Все задачи ведутся в [GitHub Issues](../../issues).
- Изменения принимаются через Pull Request.
- Состояние автоматических проверок видно во вкладке [Actions](../../actions).
- Статусы разделов обновляются в [STATUS.md](STATUS.md).

Документация описывает целевое развитие 3DCorpCod и не утверждает, что все перечисленные функции уже реализованы.
