# 3DCorpCod — главная техническая спецификация

**Версия:** 1.0  
**Дата:** 30.10.2026  
**Статус:** базовый документ требований

## 1. Назначение
3DCorpCod — браузерный редактор 3D-моделей для создания точных объектов, в том числе для 3D-печати. Tinkercad используется как ориентир пользовательского опыта, но продукт имеет собственную архитектуру, дизайн и реализацию.

## 2. Зафиксированные требования проекта
- Браузерное приложение с публикацией через GitHub Pages.
- Только тёмная тема.
- Основная целевая аудитория: начинающие и опытные пользователи.
- Моделирование для 3D-печати.
- Ввод размеров с шагом 0,1 мм; сетка рабочей области 1 мм.
- Инструменты: примитивы, текст, трансформации, линейка, выравнивание, группировка и булевы операции.
- Дополнительно: фаски и скругления граней.
- Экспорт отдельных объектов и всей сцены в STL; поддержка 3MF.
- Локальное сохранение проектов; облачные функции могут быть добавлены позднее.
- Авторская подпись: «Автор Некрут Денис».

## 4. Функциональные требования
### Сцена
- Сетка, оси X/Y/Z, камера, панорамирование, вращение, масштабирование.
- Стандартные виды и команда «Показать всё».
- Выделение одного и нескольких объектов.

### Объекты
- Создание примитивов и текстовых объектов.
- Перемещение, вращение, масштабирование, отражение.
- Числовое редактирование координат и габаритов.
- Центр объекта — pivot по умолчанию.
- Изменения не должны сбрасываться после снятия выделения.

### Точность
- Шаг числового ввода 0,1 мм.
- Сетка 1 мм.
- Внутренние значения хранятся с достаточной точностью и не округляются только из-за шага UI.

### Геометрия
- Объединение, вычитание и пересечение тел.
- Режим отверстия/инструмента вычитания.
- Обновление зависимой операции при изменении исходных объектов, если используется параметрическое дерево.
- Ошибка операции не повреждает исходную модель.
- Фаски и скругления — отдельные расширенные инструменты с предпросмотром и безопасным отказом.

### Проекты
- Создать, открыть, переименовать, дублировать и удалить.
- Подтверждение удаления.
- Автосохранение, восстановление и Undo/Redo.
- Версионирование формата проекта.

### Импорт и экспорт
- Экспорт выбранных объектов и всей сцены.
- STL и 3MF; единицы и масштаб должны быть понятны.
- Проверки пустой/повреждённой геометрии.
- Предупреждения о незамкнутых поверхностях и проблемных сетках, если они надёжно определяются.

## 5. Нефункциональные требования
- Стабильность при неудачных геометрических операциях.
- Отзывчивая навигация по сцене.
- Атомарное сохранение и возможность восстановления.
- Валидация импортируемых файлов.
- Проверка лицензий всех сторонних библиотек.
- Русский интерфейс с возможностью последующей локализации.

## 6. Критерии качества
- Размеры и координаты после редактирования совпадают с введёнными.
- Undo/Redo возвращает ожидаемое состояние.
- STL/3MF сохраняет габариты и взаимное расположение объектов.
- Экспорт проверяется независимым слайсером.
- Ошибки CI блокируют публикацию.
