# 3DCorpCod

**3DCorpCod** — браузерный редактор 3D-моделей для подготовки к 3D-печати. Планируемый адрес сайта: https://denisnekrut.github.io/3DCorpCod/

## Запуск локально

Требуется Node.js 22 или совместимая актуальная версия.

```bash
cd 3DCorpCod
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Возможности прототипа

- тёмная тема;
- просмотр сцены в 3D;
- примитивы: куб, сфера, цилиндр, конус, тор, капсула, пирамида и треугольная призма;
- выбор объекта и управление gizmo-инструментами перемещения, вращения и масштаба мышью;
- точное редактирование координат, размеров и углов;
- фаска и скругление рёбер куба;
- локальное автосохранение в браузере, открытие и сохранение проекта `.3dcc`;
- экспорт видимых объектов в STL и 3MF.

## Публикация

Файл `.github/workflows/deploy.yml` автоматически собирает веб-приложение и публикует каталог `3DCorpCod/dist` через GitHub Pages при изменениях в каталоге приложения.

Если Pages ещё не настроен, открой **Settings → Pages** в репозитории и выбери **GitHub Actions** в разделе Build and deployment.

## Ограничения прототипа

Фаска и скругление доступны для куба; полноценные геометрические операции объединения/вычитания/пересечения, обработка произвольных сеток и расширенная проверка модели для печати ещё требуют разработки. Экспорт 3MF сейчас передаёт геометрию видимых объектов и их положение/поворот, без материалов и цветовых данных.

STL не хранит единицы измерения; проект использует миллиметры. Перед печатью проверь масштаб и целостность сетки в слайсере.
