# Как собрать 3DCorpCod через GitHub без Node.js на своём компьютере

Этот проект содержит workflow GitHub Actions, который собирает Windows portable `.exe` на сервере GitHub.
На компьютере, с которого загружается исходный код, Node.js устанавливать не нужно.

## 1. Создайте репозиторий

1. Откройте https://github.com/new и войдите в GitHub.
2. Название репозитория: `3DCorpCod`.
3. Выберите Private, если хотите хранить исходный код только для себя, или Public, если готовы сделать его открытым.
4. Нажмите **Create repository**. Не добавляйте README или другие файлы, потому что они уже есть в проекте.

## 2. Загрузите файлы проекта

1. Распакуйте архив проекта.
2. Откройте созданный репозиторий на GitHub.
3. Выберите **Add file → Upload files**.
4. Загрузите содержимое папки `3DCorpCod` целиком, включая скрытую папку `.github` и файл `.github/workflows/build-windows.yml`.
5. Нажмите **Commit changes**.

Важно: на GitHub должны быть видны `package.json`, `src`, `electron` и `.github/workflows/build-windows.yml` в корне репозитория. Не загружайте внешнюю папку-обёртку `3DCorpCod` так, чтобы `package.json` оказался на один уровень глубже.

## 3. Запустите сборку

1. Откройте вкладку **Actions** репозитория.
2. Если GitHub показывает запрос на разрешение workflow, подтвердите его.
3. Выберите **Build Windows portable EXE**.
4. Нажмите **Run workflow → Run workflow**.
5. Откройте появившийся запуск и дождитесь зелёной галочки.

## 4. Скачайте EXE

В завершившемся запуске прокрутите до раздела **Artifacts** и скачайте `3DCorpCod-Windows-Portable`. Внутри архива будет `.exe`.

Если сборка завершится ошибкой, откройте шаг с красным крестиком, скопируйте последние строки лога и отправьте их в ChatGPT.

## Автоматические сборки

После добавления/изменения кода и отправки изменений в ветку `main` или `master` GitHub Actions снова соберёт программу. Если создать тег версии вида `v0.1.1`, workflow также создаст GitHub Release с EXE.

## Примечание

GitHub Actions собирает приложение, но не реализует отсутствующие функции редактора. Это пока начальный прототип; полноценные булевы операции, 3D-текст, проверка сеток и завершённый экспорт STL требуют отдельной разработки.
