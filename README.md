# 3DCorpCod

**3DCorpCod** — браузерный редактор 3D-моделей с возможностью локальной сборки переносимой версии для Windows.

## Веб-версия

Адрес после успешной публикации: https://denisnekrut.github.io/3DCorpCod/

Веб-сборка публикуется через GitHub Actions. Если адрес возвращает 404, откройте **Settings → Pages → Build and deployment** и установите **Source: GitHub Actions**. Затем повторно запустите workflow **Deploy 3DCorpCod Web App** во вкладке Actions. Workflow не может включить Pages автоматически с обычным `GITHUB_TOKEN`, если сайт ещё не создан в настройках репозитория.

## Быстрый запуск для разработки

Требуется Node.js 22 или новее.

```bash
cd 3DCorpCod
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Возможности текущего прототипа

- тёмный интерфейс для работы со сценой;
- 3D-просмотр и манипуляторы перемещения, вращения и масштаба;
- примитивы: куб, сфера, цилиндр, конус, тор, капсула, пирамида и треугольная призма;
- панель свойств и список объектов сцены;
- локальное автосохранение, открытие и сохранение проекта `.3dcc`;
- экспорт видимых объектов в STL и 3MF;
- переносимая Windows-сборка без установки.

## Сборка portable-версии Windows

1. Откройте вкладку **Actions**.
2. Выберите **Build 3DCorpCod Portable for Windows**.
3. Нажмите **Run workflow** и дождитесь успешного завершения.
4. В разделе **Artifacts** скачайте `3DCorpCod-Portable-Windows`.

## Структура репозитория

- `.github/workflows/deploy.yml` — сборка и публикация веб-версии.
- `.github/workflows/build-portable-windows.yml` — сборка Windows portable.
- `3DCorpCod/src/app` — интерфейс редактора.
- `3DCorpCod/src/components` — 3D-сцена и панели.
- `3DCorpCod/src/editor` — состояние и типы проекта.
- `3DCorpCod/src/geometry` — построение геометрии.
- `3DCorpCod/src/export` — экспорт STL/3MF.
- `3DCorpCod/electron` — оболочка Windows-приложения.

## Ограничения

Это развиваемый прототип, а не полный аналог профессионального CAD. Фаска и скругление доступны для куба; полноценные булевы операции, обработка произвольных сеток и полная проверка пригодности модели к печати ещё не реализованы. Экспорт 3MF пока не сохраняет материалы и цвета. Перед печатью проверьте размер и целостность модели в слайсере.
