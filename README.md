# 3DCorpCod

**3DCorpCod** — веб-редактор 3D-моделей для подготовки к 3D-печати.

## Открыть сервис

**Веб-версия:** https://denisnekrut.github.io/3DCorpCod/

Сервис публикуется автоматически через GitHub Actions при изменении файлов приложения. Проверить состояние сборки и публикации можно во вкладке **Actions** репозитория.

## Запуск для разработки

Требуется Node.js 22 или новее.

```bash
cd 3DCorpCod
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Возможности текущего прототипа

- тёмный интерфейс для работы со сценой;
- 3D-просмотр и манипуляторы перемещения, вращения и масштаба;
- примитивы: куб, сфера, цилиндр, конус, тор, капсула, пирамида и треугольная призма;
- панель свойств и список объектов сцены;
- локальное автосохранение, открытие и сохранение проекта `.3dcc`;
- экспорт видимых объектов в STL и 3MF.

## Структура проекта

- `.github/workflows/deploy.yml` — публикация веб-версии на GitHub Pages.
- `.github/workflows/webpack.yml` — проверка типов и сборка приложения.
- `3DCorpCod/src/app` — интерфейс редактора.
- `3DCorpCod/src/components` — 3D-сцена и панели.
- `3DCorpCod/src/editor` — состояние и типы проекта.
- `3DCorpCod/src/geometry` — построение геометрии.
- `3DCorpCod/src/export` — экспорт STL/3MF.

## Ограничения прототипа

Это развиваемый прототип, а не полный аналог профессионального CAD. Фаска и скругление доступны для куба; полноценные булевы операции, обработка произвольных сеток и полная проверка пригодности модели к печати ещё требуют доработки. Экспорт 3MF пока не сохраняет материалы и цвета. Перед печатью проверьте размер и целостность модели в слайсере.
